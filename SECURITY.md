# Security Policy

## Supported Versions

Only the latest release of `ajg/form` receives security updates. Please
make sure you are running the most recent version before reporting an issue.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately rather than opening a public issue.

- Use GitHub's [private vulnerability reporting](https://github.com/ajg/form/security/advisories/new)
  to submit a report, or
- Contact the maintainer directly.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, including a minimal code sample if possible.
- The version of `ajg/form` affected.

You can expect an initial acknowledgment within a reasonable timeframe.
Once the issue is confirmed, we will work on a fix and coordinate
disclosure with you.

Please do not disclose the vulnerability publicly until a fix has been
released.
